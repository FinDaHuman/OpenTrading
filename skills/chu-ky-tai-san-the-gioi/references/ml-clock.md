# ML Investment Clock (framework + hạn chế đã biết)

4 phases by growth/trend × inflation: Reflation→**bonds**, Recovery→**stocks**, Overheat→**commodities**, Stagflation→**cash**. The original US backtest 1973–2004, each phase averaging ~20 months.
Limits: markets run ahead of the data ("fan"); QE/geopolitics break the phase order; cash wins relatively, not absolutely.
Mapping to NBER: use `g_asset_phase` (Early/Late/Mid/Recession) instead of guessing the phase by hand whenever possible.
