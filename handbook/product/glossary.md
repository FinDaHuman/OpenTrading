# Glossary

- **Harness:** deterministic software around an LLM: context, tools, policy, budgets, sessions,
  lifecycle, and user interface.
- **Evidence:** source-preserving information that can support a report claim.
- **Fact:** a statement directly represented by evidence.
- **Calculation:** a deterministic result with named inputs and method.
- **Interpretation:** model-generated reasoning that may be useful but is not a verified fact.
- **Tool:** a bounded, typed operation offered to the model through the harness.
- **Provider:** an adapter for an LLM API; consumer chat subscriptions are not assumed to provide
  API access.
- **Capability:** observable behavior classified as implemented, specified, or deferred.
- **VN30F1M:** a continuous/current-month data convention; it must not be silently treated as a
  particular exchange contract.
